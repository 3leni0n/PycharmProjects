# ephys reports documentation

Package to generate ephys.cs and ephys reports characterizing the neral selectivity to the behaviroal task epochs

## How to use it

1. Open a terminal window, activate your python environment and go to a suitable location.

2. Download the package:

    `git clone git@github.com:balmix9/ephys_reports.git`

3. Go to the package directory.

    `cd ephys_reports`

4. Install it (remember to have your desired environment activated):

    `pip install -e .`
    
5. Run it:

    `ephys_reports`
